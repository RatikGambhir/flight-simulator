# Orbital Earth imagery

`earth-day.jpg` is the 2048 × 1024 Earth color map distributed in the Three.js
examples (NASA / Blue Marble imagery):
https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg

It is an sRGB equirectangular map. The globe uses WGS84 equatorial radius
6,378,137 m and flattening 1 / 298.257223563, with the polar axis along ECEF z.
The launch site uses a more densely tessellated patch of the same ellipsoid and
imagery. The launch pad and spacecraft are original simplified procedural models.
Night lights and the lunar map reuse the NASA assets documented in
`../atmosphere/README.md`.
